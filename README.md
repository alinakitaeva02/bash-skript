# Bash-скрипт для работы с файлами и директориями

## Описание проекта

В рамках проекта был разработан Bash-скрипт, автоматизирующий выполнение базовых операций с файлами и директориями в операционной системе Linux.

Скрипт последовательно выполняет набор команд файловой системы, выводит результаты своей работы в консоль и после завершения не оставляет временных файлов или директорий.

Проект позволил закрепить навыки работы с командной строкой Linux и написания простых сценариев автоматизации.

---

## Реализованный функционал

В процессе выполнения скрипт:

- создаёт и удаляет директории;
- создаёт, копирует, перемещает и удаляет файлы;
- изменяет права доступа к файлам;
- выполняет поиск файлов по заданным критериям;
- выводит содержимое файлов;
- осуществляет поиск текста внутри файлов;
- отображает содержимое директорий;
- выводит сообщения в консоль;
- работает с относительными путями, что позволяет запускать скрипт из любой директории.

После завершения работы скрипт очищает созданные временные данные, оставляя только вывод в терминале.

---

## Используемые команды Linux

В проекте использованы следующие команды:

- `mkdir`
- `cd`
- `touch`
- `cp`
- `mv`
- `rm`
- `chmod`
- `cat`
- `find`
- `grep`
- `ls`
- `echo`

---

## Особенности реализации

При разработке скрипта соблюдены следующие требования:

- используются только относительные пути;
- скрипт имеет права на выполнение;
- сценарий корректно запускается командой `./task.sh`;
- после завершения выполнения не оставляет созданных файлов и директорий;
- результат работы отображается в консоли.
